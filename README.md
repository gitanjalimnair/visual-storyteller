🎨 Visual Storyteller

An AI-powered web application that generates rich, descriptive narratives from images using Generative AI.

---

🚀 Features

- Upload any image
- AI analyzes visual elements and context
- Generates structured storytelling:
  - 🔍 Visual Analysis
  - 💭 Insight
  - 🎭 Mood

---

🧠 How It Works

1. Upload an image
2. Image is sent to Gemini API
3. AI generates a structured narrative

---

🖼 Example

Input: Image of Tesla and Einstein

Output:

- Visual Analysis: Scientific figures in a cosmic setting
- Insight: Represents innovation and intellect
- Mood: Nostalgic and inspiring

---

🛠 Tech Stack

- Next.js
- JavaScript
- Gemini API
- Vercel

---

▶️ Run Locally

npm install
npm run dev
