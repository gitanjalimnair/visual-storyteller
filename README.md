🎨 Visual Storyteller

An AI-powered web application that generates rich, descriptive narratives from images using Generative AI.

---

🚀 Features

- Upload any image
- AI analyzes visual elements and context
- Generates structured storytelling:
  - 🔍 Visual Analysis
  - 💭 Insight
  - 🎭 Mood

---

🧠 How It Works

1. Upload an image
2. Image is sent to Gemini API
3. AI generates a structured narrative
